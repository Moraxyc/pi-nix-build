# 界面、快捷键与耗时历史

[English](../en/ui-and-shortcuts.md) | 简体中文

## 进度组件

存在运行中的构建（前台或后台）时，`pi-nix-build` 在编辑器上方渲染实时进度组件。进度独立于工具结果行显示，即使其他扩展替换了工具行渲染，依然完整可见。

### 展示内容

1. **顶部分割线**：所有构建上方显示一条 `── ❄ Nix ───` 分割线，便于一眼将组件与编辑器及其他组件区分开。
2. **标题行**：显示折叠/展开标识（`▾` / `▸`）与单行命令摘要（多行 `-E` 表达式将折叠为单行）。折叠的构建在命令前显示其状态行。
3. **状态行**：
   - **求值阶段**：已用时间、`evaluating N files`，以及当前 `fetchTree` 操作（`⇣ ...`）或求值文件路径（省略 `/nix/store/<hash>-.../` 前缀）。
   - **构建与下载阶段**：已用时间、20 格彩色进度条（已完成、失败、阻塞、运行中、待构建）、构建计数（`done/total built`）、并行构建数（`▶ N`）、二进制缓存下载进度（`↓ done/total` 与字节数）及失败数（`✗ N`）。
4. **依赖树与传输列表**：
   - 显示活跃的 `fetchTree`、运行中与失败推导及其下游等待推导，以及活跃传输（`↓` 下载、`↑` 上传、`←` 复制，附字节进度与远程主机）。
   - 串行等待链折叠为单行：`○ a › b › c  (3 waiting)`。
   - 运行中的推导依次显示名称、stdenv 阶段进度（`1/9`–`9/9`，对应 `unpackPhase` 至 `distPhase`）、已用时间与远程构建主机（如 `builder@host`）。存在历史耗时记录时，已用时间后附带 `/ ~<预估>`，超出预估后以警告色提示。
5. **尾行**：展开的构建在依赖树下方显示 `⤢ details`，点击打开详情视图（非全屏 TUI 模式下显示 `⤢ ctrl+shift+m`）。依赖树被截断时，尾行显示为 `… N more  ⤢ details`。

### 图标

默认使用 [Nerd Fonts](https://www.nerdfonts.com/) 图标。设置 `PI_NIX_BUILD_NERD_FONT=0` 后改用普通 Unicode 符号；终端无法告知字体是否包含 Nerd Font 字形，因此不会自动检测。本文档中的符号均为普通形式。

| 含义                     | Nerd Font 字形                                                | 普通符号        |
| ------------------------ | ------------------------------------------------------------- | --------------- |
| Nix（顶部分割线）        | `nf-linux-nixos`                                              | `❄`             |
| 构建已折叠 / 已展开      | `nf-cod-chevron_right` / `nf-cod-chevron_down`                | `▸` / `▾`       |
| 详情视图                 | `nf-oct-screen_full`                                          | `⤢`             |
| 运行中                   | `nf-cod-play`                                                 | `▶`             |
| 已完成                   | `nf-cod-check`                                                | `✓`             |
| 失败                     | `nf-cod-close`                                                | `✗`             |
| 因依赖失败而阻塞、已取消 | `nf-cod-circle_slash`                                         | `⊘`             |
| 等待中                   | `nf-cod-circle`                                               | `○`             |
| 下载 / 上传 / 复制       | `nf-cod-arrow_down` / `nf-cod-arrow_up` / `nf-cod-arrow_left` | `↓` / `↑` / `←` |
| 获取源码（`fetchTree`）  | `nf-cod-cloud_download`                                       | `⇣`             |
| 后台任务消息             | `nf-cod-server_process`                                       | `◆`             |

### 显示模式与行数上限

组件密度由两项独立设置控制：

- **组件折叠**（`Ctrl+Shift+B` 或点击标题行）：
  - **单个构建**：默认展开；在完整进度树与一行摘要之间切换。
  - **多个构建**：默认全部折叠为每个一行，同一时间最多展开一个。点击标题展开该构建并折叠此前展开的构建，再次点击则折叠。`Ctrl+Shift+B` 从第一个到最后一个依次展开，之后全部折叠。各构建始终按启动顺序排列。
- **pi 工具展开模式**：控制完整进度树下的最大显示行数与日志预览行数。构建或下载开始后，组件将最大行数锁定为 `min(上限, 计划构建数 + 计划下载数)`，避免上方对话内容反复跳动：
  - **默认状态（工具折叠）**：最多 10 行；不显示运行中推导的日志，失败推导显示最后 8 行日志。
  - **工具展开状态**：最多 30 行；运行中推导显示最后 5 行日志，失败推导在剩余行数内最多显示 80 行已捕获日志。
  - 尾行不计入上述行数上限。

## 全屏详情视图

按 `Ctrl+Shift+M` 打开当前展开的构建；没有展开的构建时，打开最近一次构建，构建进行中或结束后均可打开。全屏 TUI 模式下，点击某个构建尾行的 `⤢ details` 打开该构建。

- **布局**：终端宽度 `>= 100` 列时左右分栏（左侧依赖树，右侧日志）；较窄终端自动切换为上下分栏。
- **依赖树面板**：列出本次构建的全部推导（含已完成项）及活跃传输。默认选中首个运行中推导，其次为首个失败推导或首项。
- **日志面板**：显示推导名称、状态、阶段、远程主机，以及内存中保留的最近 200 行日志（无日志时显示 Nix 报错文本）。向上滚动后锁定当前视口，并在新日志到达时显示 `↓ N newer lines`。

## 键盘与鼠标操作

### 全局快捷键

| 快捷键         | 功能                                                       |
| -------------- | ---------------------------------------------------------- |
| `Ctrl+Shift+B` | 单个构建：切换其依赖树。多个构建：依次展开，之后全部折叠。 |
| `Ctrl+Shift+M` | 打开当前展开构建的全屏详情视图，否则打开最近一次构建。     |

### 详情视图按键

| 按键                   | 功能                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| `↑` / `↓` 或 `k` / `j` | 在依赖树中上下移动选中项。                                        |
| `←` / `→` 或 `h` / `l` | 左右滚动依赖树。移动选中项时也会自动滚动，保持其可见。            |
| `PgUp` / `PgDn`        | 日志面板上下翻页。                                                |
| `g` / `Home`           | 跳转至日志顶部。                                                  |
| `G` / `End`            | 跳转至日志底部并恢复自动跟随。                                    |
| `o`                    | 用 `$PAGER`（默认 `less`）只读打开选中构建的完整日志。            |
| `e`                    | 用 `$VISUAL` / `$EDITOR`（默认 `vi`）只读打开选中构建的完整日志。 |
| `Esc` / `q`            | 关闭详情视图。                                                    |

为保持轻量，内存只保留每个构建的最后 80 行，运行结束后只留失败构建的。选中成功的构建时，日志面板从本次运行的日志文件读取其完整日志。`o` 和 `e` 始终从该文件读取完整日志，构建进行中也可用，并写入该日志旁的一个只读文件。

### 鼠标操作（仅全屏 TUI 模式）

pi 仅在全屏 TUI 模式下向组件分发鼠标事件：

- **进度组件**：左键点击命令标题展开或折叠该构建；左键点击尾行的 `⤢ details` 打开详情视图。
- **详情视图**：左键点击推导行查看对应日志；在依赖树区域滚动滚轮切换选中项，按住 `Shift` 则左右滚动依赖树；在日志区域滚动滚轮浏览日志。

## 构建耗时历史与预估

本地记录已完成构建的耗时，用于预估后续构建时间：

- **存储路径**：`$XDG_STATE_HOME/pi-nix-build/durations.json`（默认 `~/.local/state/pi-nix-build/durations.json`）。
- **保留策略**：按 `<name>@<host>`（本地构建为 `local`）各自保留最近 10 次记录。
- **预估规则**：取历史样本中位数。若精确键无记录（例如软件包版本更新后），回退匹配同一主机上的同 `pname`（去除 `-<version>` 后缀）记录。
- **并发写入**：写入前先读取磁盘文件合并，再通过临时文件原子重命名替换，防止多个 pi 会话相互覆盖。
